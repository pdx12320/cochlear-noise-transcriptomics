# Publication copies

Original execution files remain private and unchanged. Public copies retain numerical results and sample identities. Only literal machine-local root/environment path fields in text were replaced by generic tokens. No scientific values, thresholds, labels, memberships or code parameters were altered by publication preparation. Failed pilot implementation attempts are excluded from this public bundle and retained in the private execution record.

`SOURCE_PUBLIC_SHA256.tsv` records the source and public SHA-256 for every copied file and identifies the transformation. The independent result audit verified all 899 original retrieved-file hashes, all 48 fits and the unchanged 42 source records before publication preparation. `PUBLIC_SHA256SUMS.txt` covers the final public tree.
