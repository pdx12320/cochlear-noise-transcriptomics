# GSE252285 robust-QC no-doublet t-SNE methods

The public GSE252285 processed count matrix contained 32,285 features and 39,092 barcodes. Input dimensions, identifiers, duplicate symbols, feature types, missing values and barcode suffixes were audited before object creation. Gene symbols were used as feature names with traceable uniqueness handling and retained source gene IDs.

Quality control was calculated separately by library using `nCount_RNA`, `nFeature_RNA` and case-insensitive mouse mitochondrial symbols. Cells were required to have at least 200 detected genes. Library-specific upper outliers in feature count, UMI count and mitochondrial percentage were identified using the fixed robust quantile/MAD rules recorded in the external `QC_THRESHOLDS.tsv`. Exactly 36,111 barcodes passed robust QC. This selected branch applied no doublet filter and imported no scDblFinder field.

The 36,111-cell sparse object was log-normalized with scale factor 10,000. Two thousand variable genes were selected using Seurat `vst`, scaled and used to calculate 50 PCs. PCs 1–30 were pre-specified for a k=20 neighbor graph. Louvain clustering used algorithm 1, seed 42, 10 starts and 10 iterations. Resolution 0.6 was fixed before analysis and yielded 28 clusters. Resolutions 0.4, 0.8 and 1.0 were audited but not used to select the main result; they yielded 27, 33 and 37 clusters. No integration was applied.

t-SNE was computed from PCs 1–30 with seed 42 and perplexity 30. UMAP was not run for this branch. t-SNE geometry was used for visualization only and not as cell-identity evidence.

Cluster markers were calculated with Seurat Wilcoxon tests. Annotation evidence emphasized effect size, `pct.1`, `pct.2`, `pct.1-pct.2`, multi-gene canonical programs and specificity rather than p-values alone. The broad annotation remained provisional where evidence conflicted. A focused audit assessed erythroid, neuronal/SGN, glial, epithelial, endothelial, mural, mesenchymal and immune programs for clusters 6/9/13/19.

Broad labels used a barcode-level prior from 31,273 shared cells, supplied as `inputs/annotation_reference.tsv` with source-object and table hashes. Within each selected cluster, the majority reference label was retained only with at least 20 shared cells, majority purity of at least 0.70 and at least two supporting canonical markers (mean expression at least 0.10 and expressing fraction at least 0.05). Lineage scores were the mean marker-level product of mean expression and expressing fraction. The original 0.75-of-top and 1.5-fold competing-lineage checks were preserved; conflicting or unsupported clusters remained UNRESOLVED. An additional-cell fraction of at least 0.30 generated a warning but did not independently change the label. The portable input adapter reproduced all 28 labels, confidences, reasons and warnings; no annotation thresholds or scientific results changed.

The Top20 list and order were fixed before localization. Expression summaries use sparse RNA counts for detection and the Seurat RNA data layer for mean/median log-normalized expression. Condition mapping was resolved by observed suffix: `-3=Control`, `-1=HHL`, `-2=NIHL`, corresponding to LIB3/LIB1/LIB2. Condition and cell-type composition outputs are descriptive. No cell-level condition DE, differential-abundance significance test or biological-replicate inference was performed.
