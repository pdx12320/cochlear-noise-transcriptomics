\section*{Data Availability}
The sequencing datasets are available from the Gene Expression Omnibus under accessions GSE168041, GSE160639 and GSE252285. The manuscript and figure source data are archived in release v1.2.2 at \url{https://github.com/pdx12320/cochlear-noise-transcriptomics}. The repository README provides version-pinned links to gene-level and pathway results, sample summaries, expression-localization tables and sensitivity-analysis records. Complete sensitivity bundles remain available in release v1.1.0, and baseline analysis objects in release v1.0.0.

\section*{Code Availability}
Scripts for GSE168041 preprocessing, annotation, pseudobulk differential expression and enrichment, and for GSE252285 expression localization and matched-null analysis are available in the repository. Current manuscript sources and figure-generation scripts are archived in release v1.2.2 at \url{https://github.com/pdx12320/cochlear-noise-transcriptomics}. The repository README links to the raw-count bulk workflows, leave-one-animal-out analyses, annotation-sensitivity analyses and required public inputs. Software versions, input manifests and file checksums accompany the workflows.
